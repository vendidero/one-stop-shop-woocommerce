# Security Policy

## Supported Versions

Generally, only the latest version of One Stop Shop for WooCommerce has continued support. If a critical vulnerability is found in the current version of One Stop Shop for WooCommerce, we may opt to backport any patches to previous versions.

## Reporting a Vulnerability

One Stop Shop for WooCommerce is an open-source plugin for WordPress. Please report security bugs found in the source code of the One Stop Shop for WooCommerce plugin through the [Patchstack Vulnerability Disclosure Program](https://patchstack.com/database/vdp/c871de9d-95a9-43bf-86f0-cc4167c2a18f). The Patchstack team will assist you with verification, CVE assignment, and notify the developers of this plugin.
